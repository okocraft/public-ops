# public-ops

A collection of automation workflows, scripts, and operational tools that can be safely shared publicly.

## Overview

This repository contains reusable automations and utilities for simplifying operational tasks.

It serves as a central place to organize, maintain, and share automation resources.

## Contents

- **Workflows** — Automated processes and GitHub Actions
- **Scripts** — Utility scripts for operational tasks
- **Tools** — Reusable tools and integrations
- **[Releaser](releaser/README.md)** — Planned GitHub Release automation for Gradle/Maven projects
- **[Paper E2E](paper-e2e/README.md)** — Harness and helper plugin for end-to-end tests of Paper plugins with real protocol clients

## Guidelines

- Keep automations simple, reusable, and well-documented.
- Never commit secrets, credentials, or sensitive information.
- Avoid including internal-only configurations or proprietary data.
- Provide setup and usage instructions where necessary.

## Usage

Refer to the documentation in each directory for setup and usage details.
